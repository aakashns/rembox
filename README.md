# rembox has moved

REMBOX now lives in [aakashns/aak.sh](https://github.com/aakashns/aak.sh/tree/main/rembox).
Visit [rembox.aak.sh](https://rembox.aak.sh) for the setup guide and installer.

- **Existing installations** can run `rembox upgrade` to install the [0.27.1 bridge](https://github.com/aakashns/rembox/releases/tag/v0.27.1). Run it again to check the monorepo for later releases.
- **Fresh installations** can run `curl -fsSL https://rembox.aak.sh/install.sh | sh`.
- [Current releases](https://github.com/aakashns/aak.sh/releases?q=rembox-v), [issues](https://github.com/aakashns/aak.sh/issues), and [pull requests](https://github.com/aakashns/aak.sh/pulls) are in the monorepo. [Historical binaries and checksums](https://github.com/aakashns/rembox/releases) remain here for pinned installs.
