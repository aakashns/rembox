GitHub Changelog

Set up and manage
remote dev machines

Turn any Ubuntu or Debian server into a locked-down box with secure SSH, developer tools, AI coding agents, and remote access from your phone.

Run this on Mac, Linux, or WSL to install rembox:

curl -fsSL https://rembox.aakashns.com/install.sh | sh

Run rembox setup to begin setting up a remote server.

What does rembox setup do?

  1. Saves your server’s details and keeps it up to date
    • asks you for the server’s IP/host, SSH port, key file, and username
    • saves it to ~/.ssh/config, so you can connect with ssh <name>
    • logs in, upgrades all packages, and turns on unattended-upgrades
    • adds swap as big as the server’s memory (up to 4 GiB), if it has none
  2. Locks down incoming network traffic and SSH access
    • creates a non-root user with password protected sudo access
    • moves SSH from 22 to a random port to counter automated attacks
    • turns off password-based & root SSH access, and turns on fail2ban
    • turns on the ufw firewall to block all incoming traffic except SSH
  3. Installs development tools and configures the shell
    • installs git, gh, ripgrep, fd, fzf, jq, htop, Zellij, and other dev tools
    • installs the latest Node (with Vite+), bun, Python (with uv), Rust and Go
    • makes zsh your shell, with curated plugins to improve your workflow
    • sets your name and email for git, and logs gh in to GitHub with a code
  4. Installs AI coding agents and sets up remote access
    • installs & sets up Claude Code, Codex, OpenCode, and Pi coding agents
    • installs Playwright with Chromium, so agents can do browser testing
    • installs opentunnel, so agents can share dev server links on your phone
    • installs T3 Code and configures secure remote access via T3 Connect
    • displays a QR code to set up T3 Code on your phone for remote access

You can re-run rembox setup <MACHINE> anytime to update or fix your setup. rembox prints every command it runs, check the server scripts for details.

CLI Commands

rembox setup [NAME]
Sets up a server, as above, or with NAME, sets one up again.
rembox list
Lists the servers you’ve added, with the user, host, port and key rembox logs in with.
rembox ssh NAME [COMMAND...]
Logs in to the server called NAME as configured, or runs a command on it.
rembox tunnel NAME SERVER-PORT:LOCAL-PORT
Forwards SERVER-PORT to localhost:LOCAL-PORT, until Ctrl-C; give one PORT for both.
rembox remove NAME
Removes a server’s login details and ssh alias; the server itself stays as it is.
rembox help [command]
Lists the commands, or explains one of them.
rembox version
Prints the version, and the commit it was built from.
rembox upgrade
Upgrades rembox to the latest release.
rembox implode
Removes rembox, ~/.config/rembox, and the line added to ~/.ssh/config.

FAQs

Where should I install rembox: my laptop or the remote server?
On your laptop/desktop (Mac, Linux, or WSL). rembox logs in to the server over ssh and sets it up from there, so you don’t need to install anything on the server first.
What servers does rembox work on?
Any Ubuntu or Debian server you can ssh into with a key, as root or a user with sudo, from any provider. A fresh one works best, since rembox sets up the firewall and SSH its own way.
Can I run rembox on a server I already use?
Yes. Each step checks the server first and changes only what needs changing. If ufw already lets something in, like a web server on port 80, rembox asks whether to keep each of those rules; any other incoming traffic but SSH gets blocked.
I can’t connect after the SSH port changed. What now?
Your cloud provider probably has a firewall of its own. Open the new port in it, then run rembox setup <MACHINE> again to pick up where it left off.
How do I open a dev server running on the machine?
Ask the agent for an opentunnel link: opentunnel route add 3000 prints a public https link to port 3000 that you can open on your phone. From your laptop, you can also run rembox tunnel <MACHINE> 3000, so localhost:3000 on your laptop reaches port 3000 on the server.
What does rembox keep on my laptop?
Only how to log in to each server, in ~/.config/rembox, and one line in ~/.ssh/config that includes it. Nothing about the server itself.
How do I upgrade or uninstall rembox?
Run rembox upgrade, with sudo if it’s in /usr/local/bin. To remove rembox and everything it keeps on your laptop, run rembox implode.
Can I install a specific version, or in another folder?
Yes. Set REMBOX_VERSION (like 0.1.0) or REMBOX_INSTALL_DIR (instead of /usr/local/bin) for the install script: 
curl -fsSL https://rembox.aakashns.com/install.sh \
  | REMBOX_VERSION=0.1.0 REMBOX_INSTALL_DIR="$HOME/.local/bin" sh
How do I verify a release?
Releases are built by GitHub Actions, and the install script and rembox upgrade check every download against its SHA256SUMS. To check a binary’s signed build attestation: 
gh attestation verify "$(command -v rembox)" --repo aakashns/rembox
Something went wrong, or I have an idea. What do I do?
First, run rembox upgrade to get the latest version, then run rembox setup <MACHINE> again. If it still goes wrong, open an issue on GitHub with what you ran and what it printed, or send a pull request.
What does rembox install and set up on the server?

Security

  • ufw blocks every incoming connection except SSH.
  • fail2ban bans addresses that keep failing to log in.
  • unattended-upgrades installs security updates every day.
  • sudo is password-protected root for your user.
  • locales adds your Mac’s locale, so programs don’t warn.

Dev tools

  • build-essential is gcc, g++, make, and the headers they need.
  • git is version control.
  • gh is GitHub’s command line, from GitHub’s apt repo, not the distro’s.
  • curl fetches a URL.
  • wget downloads a file, and retries if it fails.
  • zip packs files into a .zip.
  • unzip unpacks a .zip.
  • jq reads and edits JSON.
  • ripgrep searches through files. The command is rg.
  • fd finds files by name.
  • htop is a live view of processes, CPU, and memory.
  • nano is a simple text editor.
  • man shows manual pages.
  • dnsutils is dig and nslookup.
  • qrencode draws the QR code for T3 Code’s phone app.

Shell

  • zsh is your login shell.
  • zinit loads the plugins below.
  • zsh-syntax-highlighting colors a command as you type it.
  • zsh-autosuggestions suggests the rest of a command from your history.
  • zsh-completions adds extra tab completions.
  • Oh My Zsh git adds aliases like gst, gco, and ggpush.
  • fzf is a fuzzy finder. Ctrl-R searches history, Ctrl-T finds files, Alt-C changes folder.
  • zoxide jumps to folders you’ve used. z matches a name; zi picks one with fzf.
  • Zellij is a terminal workspace. An SSH login starts it locked; Ctrl+g unlocks it.

Languages

  • Vite+ installs and runs Node. The command is vp.
  • Node is the latest release, as Vite+’s default.
  • bun is the latest release, in ~/.bun.
  • uv installs Python.
  • Python is the latest uv can install, as python and python3.
  • rustup installs and updates Rust.
  • Rust is the latest stable, with cargo, clippy, and rustfmt.
  • Go is the latest release, in /usr/local/go.

Coding agents. Setup asks before each of these. No skips that one.

  • Claude Code is Anthropic’s coding agent. Logs in with a link.
  • Codex is OpenAI’s coding agent. Logs in with a code, or an API key.
  • OpenCode is an open-source agent for many model providers.
  • Pi is a small agent you can extend. Log in with /login.

Browser testing

  • Playwright runs browser tests for the agents.
  • Chromium is the browser Playwright drives, plus the libraries it needs.

Remote access

  • T3 Code runs in the background. Your phone and browser reach it through T3 Connect, with no ports opened.
  • opentunnel gives a dev server a public link, so you can test it on your phone.
