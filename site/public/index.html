GitHub Changelog

Remote dev boxes,
set up securely

rembox turns a fresh Ubuntu server into a secure remote development machine, and helps you manage it from your Mac.

Run this on your Mac (or a Linux machine) to install rembox:

curl -fsSL https://rembox.aakashns.com/install.sh | sh

Early days. So far rembox setup installs updates, adds your user, moves ssh to another port with keys only, and sets up fail2ban. More steps are coming.

Commands

rembox setup [NAME]
Adds a server (or, with NAME, changes one), then installs updates, adds your user (whose sudo asks for its password), locks down ssh, sets up fail2ban, and restarts it if needed. Offers to set up ~/.ssh/config so ssh NAME works too.
rembox list
Lists the servers you’ve added, with the user, host, port and key rembox logs in with.
rembox ssh NAME [COMMAND...]
Logs in to the server called NAME, as its user, on its port and with its key, or runs a command on it.
rembox help [command]
Lists the commands, or explains one of them.
rembox version
Prints the version, and the commit it was built from.
rembox upgrade
Upgrades rembox to the latest release.
rembox implode
Removes rembox, ~/.config/rembox, and the line setup added to ~/.ssh/config.

rembox prints every command it runs, including those in its server scripts, and asks before destructive ones.

Installing

Run the install command again to reinstall or upgrade. Two environment variables change what it does:

REMBOX_VERSION
Installs this version, like 0.1.0, instead of the latest.
REMBOX_INSTALL_DIR
Installs in this folder instead of /usr/local/bin.
curl -fsSL https://rembox.aakashns.com/install.sh \
  | REMBOX_VERSION=0.1.0 sh

Releases have a binary for macOS and Linux, on both Apple Silicon/ARM and Intel/AMD processors.

Upgrading and uninstalling

Run rembox upgrade with sudo if rembox is in a folder only root can write to, like /usr/local/bin. 

sudo rembox upgrade
rembox implode

Verifying a release

Every release is built by GitHub Actions from the main branch, with a SHA256SUMS file that both the install script and rembox upgrade check downloads against. Each binary also has a signed build attestation, which you can check with the GitHub CLI: 

gh attestation verify "$(command -v rembox)" --repo aakashns/rembox
